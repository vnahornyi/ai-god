# SEO sources for web developers

Prefer current official documentation from the search engine or browser that owns the behavior. These links primarily describe Google Search; do not present them as universal rules for every search engine.

## Start here

- [SEO Starter Guide](https://developers.google.com/search/docs/fundamentals/seo-starter-guide) — approachable overview of how to help search engines understand pages and users find them.
- [Ecommerce SEO overview](https://developers.google.com/search/docs/specialty/ecommerce) — entry point for product data, site structure, reviews, URLs, and pagination.

## Rendering, discovery, and URLs

- [JavaScript SEO basics](https://developers.google.com/search/docs/crawling-indexing/javascript/javascript-seo-basics) — Google crawling, rendering, indexing, initial HTML, and JavaScript pages.
- [Pagination and incremental page loading](https://developers.google.com/search/docs/specialty/ecommerce/pagination-and-incremental-page-loading) — pagination, load more, infinite scroll, and crawler-discoverable links.
- [Managing faceted navigation URLs](https://developers.google.com/crawling/docs/faceted-navigation) — how filter combinations can create excessive crawlable URLs and how to make an intentional policy.
- [Ecommerce URL structure](https://developers.google.com/search/docs/specialty/ecommerce/designing-a-url-structure-for-ecommerce-sites) — stable, understandable URLs, pagination, and product variants.
- [Ecommerce site structure](https://developers.google.com/search/docs/specialty/ecommerce/help-google-understand-your-ecommerce-site-structure) — internal navigation and links that help crawlers discover important pages.

## Product data and reviews

- [Product snippets](https://developers.google.com/search/docs/appearance/structured-data/product-snippet) — Product/Offer/Review data, page scope, and testing steps.
- [Product variants](https://developers.google.com/search/docs/appearance/structured-data/product-variants) — representing variants that belong to one product group.
- [Review snippets](https://developers.google.com/search/docs/appearance/structured-data/review-snippet) — item-specific reviews, visible rating data, and supported properties.
- [Structured data introduction and testing](https://developers.google.com/search/docs/appearance/structured-data/intro-structured-data) — why markup is used, quality rules, and Rich Results Test.

## Diagnose the deployed page

- [Search Console URL Inspection](https://support.google.com/webmasters/answer/9012289) — indexed URL status and live rendered-page inspection.
- [Core Web Vitals](https://web.dev/articles/vitals) and [measurement workflow](https://web.dev/articles/vitals-measurement-getting-started) — user-centric performance metrics and the difference between field and lab data.
- [Bing Webmaster Guidelines](https://www.bing.com/webmasters/help/webmaster-guidelines-30fba23a) — use when Bing or Microsoft search experiences are in scope; its guidance is engine-specific.
